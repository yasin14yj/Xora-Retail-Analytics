# Xora-Retail-Analytics
Xora Retail Performance Dashboard 📊

**Project Overview**
The Xora Retail Performance Dashboard is an end-to-end data analytics project designed to simulate a real-world retail business environment. The primary objective of this project is to transform raw sales data into actionable business intelligence, providing insights into revenue trends, regional performance, and customer behavior.

Through this project, I have demonstrated proficiency in the full data analytics lifecycle:
1. Data Engineering: Developed synthetic datasets to model complex sales scenarios and implemented a robust Star Schema architecture to ensure data integrity and query efficiency.
2. Database Management: Managed the data lifecycle by ingesting datasets into MySQL, performing data cleaning, and executing complex SQL queries to extract performance metrics.
3. Business Intelligence: Designed an interactive Power BI dashboard featuring executive-level KPIs, advanced visualizations, and interactive slicers for deep-dive analysis.

**Project Workflow**
1. Data Generation: Used Python (Faker, Pandas) to simulate 1,000+ realistic retail transactions.
2. Data Ingestion: Cleaned and imported datasets into MySQL for relational data management.
3. Data Modelling: Constructed a Star Schema in Power BI to enable seamless data relationship management.
4. Data Analysis & Visualization: Executed complex SQL queries for deep-dive insights and built an interactive dashboard to communicate findings.

**Technical Skills Demonstrated**
1. Tools: Power BI (DAX, Power Query), MySQL Workbench, Python (Pandas, Faker, Seaborn).
2. Concepts: Star Schema Architecture, Exploratory Data Analysis (EDA), Relational Database Management, Business Intelligence.
